Inventory Rescue

Inventory Rescue is a personal, single-user, local inventory-management application. It runs on its operator's own computer and is not a publicly hosted or publicly available service — this page does not host or run the application. This page exists to describe Inventory Rescue for eBay Developer Program review purposes.

What it does

Inventory Rescue helps its operator manage physical resale inventory: tracking items on hand, researching comparable listings to inform pricing, and preparing and publishing the operator's own eBay listings through seller-authorized eBay API workflows (OAuth-based, scoped to the operator's own account).

Media Hunter (experimental)

Media Hunter is an experimental, in-development workflow within Inventory Rescue that identifies physical DVD, CD, and VHS media from shelf photographs and supports resale research for the items it recognizes.

Marketplace Insights

If approved for the eBay Marketplace Insights API, Inventory Rescue would use eBay sold-listing market evidence to evaluate items recognized by Media Hunter and other Rescue workflows — for example, checking whether a recognized item shows genuine resale demand before the operator spends time listing it. This use would be evaluation-only, scoped to the operator's own research, with no data shared or sold to any third party.
