Inventory Rescue — Privacy Policy

Inventory Rescue is a personal, single-user, local inventory-management application. It is not a public service, does not have other users, and is not operated as a business. This page exists to satisfy eBay's Developer Program requirement that an application requesting user-level API access provide a privacy policy URL.

What data this application accesses

Inventory Rescue connects to the eBay Sandbox and/or Production APIs, using OAuth, solely to manage the operator's own inventory listings (creating and updating draft listings, reading the operator's own business policies and inventory locations). It does not access any other eBay user's account or data.

Where data is stored

All data — including eBay OAuth tokens and any information retrieved from eBay's API — is stored locally, in a SQLite database on the operator's own computer. Nothing is transmitted to any third-party server, analytics service, or advertising network. Nothing is sold or shared.

Contact

This application has a single operator, who is also its sole user.
